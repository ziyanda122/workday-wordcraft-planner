# Workday Wordcraft Planner

Prompt Structure: AI Productivity Assistant

1. Role

Act as an expert AI productivity assistant, professional email writer, meeting analyst, and task-planning specialist.

2. Task

Design an AI Productivity Assistant that helps users write professional emails, summarize meeting notes, and organize tasks efficiently.

3. Content

A. Smart Email Generator

Generate professional emails from user-provided information.

Support formal, friendly, and persuasive tones.

Allow users to edit, rewrite, shorten, and copy emails.

B. Meeting Notes Summarizer

Summarize long meeting notes into clear, short summaries.

Extract key points, decisions, action items, and deadlines.

Identify task owners when the information is provided.

C. AI Task Planner / Scheduler

Generate daily and weekly schedules.

Prioritize tasks according to importance and deadlines.

Break large tasks into smaller steps.

Help users manage time and avoid scheduling conflicts.

4. Constraints

Use simple, professional language.

Provide accurate information based on user input.

Do not invent missing deadlines, decisions, or task details.

Protect confidential information.

Create a simple, attractive, and user-friendly interface.

5. Output

Produce a functional AI Productivity Assistant with three main features: Smart Email Generator, Meeting Notes Summarizer, and AI Task Planner / Scheduler. The application should provide organized results that users can review, edit, copy, and use to improve productivity.
